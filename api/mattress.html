mattress package¶

class mattress.InitializedMatrix(ptr)[source]¶

Bases: object

Pointer to an object containing a tatami::Matrix, typically generated by initialize() for use in C++ code. Instances of this class should only be created by developers and used within package functions; this is done by passing the ptr address to C++ and casting it to a pointer to a mattress::BoundMatrix (see the mattress.h header). All InitializedMatrix instances are expected to be transient within a Python session; they should not be serialized, nor should they be visible to end users. Each instance will automatically free the C++-allocated memory upon garbage collection.

__init__(ptr)[source]¶

This constructor should only be called by registered methods for initialize().

Parameters:

ptr (int) – Address of a mattress::BoundMatrix instance. This is typically obtained by passing a std::uintptr_t from C++ code.

Type of the matrix, to masquerade as a NumPy-like object. This is always a double-precision type.

Examples

>>> ptr.dtype

Return type:

>>> import mattress
>>> mat = numpy.random.rand(1000, 20)
>>> ptr = mattress.initialize(mat)
>>> ptr.get(True, 0)
group_median(row, group, num_threads=1)[source]¶

Convenience method to compute the median for each group of rows or columns.

Parameters:

  • row (bool) – Whether to compute the row-wise median for each group of columns. If False, column-wise medians are computed for each group of rows instead.

  • group (Sequence) – Sequence of length equal to the number of columns (if row = True) or rows (otherwise) of the matrix, containing the group assignment for each column/row.

  • num_threads (int) – Number of threads.

Return type:

Tuple[ndarray, list]

Returns:

Tuple of length 2. The first element is a 2-dimensional array:

  • If row = True, each column of the array represents a group, while each row corresponds to a row of the tatami::Matrix. Each entry contains the row-wise median for a group.

  • If row = False, each row of the array represents a group, while each column corresponds to a column of the tatami::Matrix. Each entry contains the column-wise median for a group.

The second tuple element is a list containing the unique levels of group represented by each row/column in the aforementioned array.

Examples

>>> import numpy
>>> import mattress
>>> mat = numpy.random.rand(10, 20)
>>> ptr = mattress.initialize(mat)
>>> group = ["A", "B"] * 10
>>> ptr.group_median(True, group)

Convenience method to compute the variance for each group of rows or columns.

Parameters:

  • row (bool) – Whether to compute the row-wise variance for each group of columns. If False, column-wise variances are computed for each group of rows instead.

  • group (Sequence) – Sequence of length equal to the number of columns (if row = True) or rows (otherwise) of the matrix, containing the group assignment for each column/row.

Tuple[ndarray, list]

Returns:

Tuple of length 3. The first two elements are 2-dimensional arrays containing the per-group mean and variances, respectively:

  • If row = True, each column of the array represents a group, while each row corresponds to a row of the tatami::Matrix. Each entry contains the row-wise mean or variance for a group.

  • If row = False, each row of the array represents a group, while each column corresponds to a column of the tatami::Matrix. Each entry contains the column-wise mean or variance for a group.

The third tuple element is a list containing the unique levels of group represented by each row/column in the aforementioned arrays.

Examples

>>> import numpy
>>> import mattress
>>> mat = numpy.random.rand(10, 20)
>>> ptr = mattress.initialize(mat)
>>> group = ["A", "B"] * 10
>>> ptr.group_variance(True, group)
